# Erosion-of-Seasonality-Anomalies-in-US-Equity-Markets
This report investigates seasonal anomalies in the US equity market (1980–2023). It focuses on the empirical analysis of monthly and daily seasonality within S&P 500, with backtested trading strategies to assess profitability decay over time.

# Key Findings
- **Seasonality Evidence**: Nov-May outperforms Jun-Oct, Excess returns on the turn of each month
- **Strategy Performance**: 9.20% annual return with 15.7% volatility
- **Profitability Erosion**: Alpha decay in post-2000 arrtibuted to technological advances reducing market inefficiencies
